┌─────────────────────────────────────────────────────────┐
│ INSTALACIÓN EN 3 PASOS                                  │
└─────────────────────────────────────────────────────────┘

1. INSTALAR DEPENDENCIAS

   Fedora:
   $ sudo dnf install gcc make raylib-devel

   Ubuntu:
   $ sudo apt install gcc make libraylib-dev

   O usa el instalador automático:
   $ chmod +x install.sh
   $ ./install.sh


2. COMPILAR

   $ make


3. EJECUTAR

   $ ./hex -t 4 -s 1000

┌─────────────────────────────────────────────────────────┐
│ COMANDOS ÚTILES                                         │
└─────────────────────────────────────────────────────────┘

# Ver todas las opciones
$ make help

# Versión consola (sin GUI)
$ ./hex_console -t 4 -s 1000

# Prueba rápida
$ make run-test

# Juego normal
$ make run

# Máxima potencia
$ make run-fast

# Tests automáticos
$ ./test.sh

┌─────────────────────────────────────────────────────────┐
│ CONTROLES DEL JUEGO                                     │
└─────────────────────────────────────────────────────────┘

GUI:
   • Click izquierdo: Colocar ficha
   • R: Reiniciar
   • ESC: Salir

Consola:
   • Escribir jugada: A1, B2, K11, etc.
   • quit: Salir

┌─────────────────────────────────────────────────────────┐
│ OPCIONES DE CONFIGURACIÓN                               │
└─────────────────────────────────────────────────────────┘

-t <threads>        Número de threads (1-32, default: 4)
-s <simulaciones>   Simulaciones por thread (default: 1000)

Ejemplos:
   $ ./hex -t 2 -s 100      # Rápido (para pruebas)
   $ ./hex -t 4 -s 1000     # Normal
   $ ./hex -t 8 -s 2000     # Potente
   $ ./hex -t 16 -s 5000    # Muy potente (lento)

┌─────────────────────────────────────────────────────────┐
│ SOLUCIÓN DE PROBLEMAS                                   │
└─────────────────────────────────────────────────────────┘

ERROR: "raylib not found"
   → Instala raylib-devel (Fedora) o libraylib-dev (Ubuntu)

ERROR: "pthread not found"
   → Instala glibc-devel

ERROR: Compilación falla
   → Verifica que tienes GCC: gcc --version
   → Ejecuta: make clean && make

ERROR: GUI no funciona
   → Usa la versión consola: ./hex_console

LENTO: IA tarda mucho
   → Reduce threads o simulaciones: ./hex -t 2 -s 100

┌─────────────────────────────────────────────────────────┐
│ MÉTRICAS DE RENDIMIENTO                                 │
└─────────────────────────────────────────────────────────┘

Tiempos aproximados por turno de IA:

   1 thread,  1000 sims → ~12s
   2 threads, 1000 sims → ~6s   (2.0x)
   4 threads, 1000 sims → ~3s   (4.0x)
   8 threads, 1000 sims → ~1.5s (8.0x)
