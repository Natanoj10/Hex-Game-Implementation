┌──────────────────────────────────────────────────────────────────┐
│ ALGORITMO MONTE CARLO                                            │
└──────────────────────────────────────────────────────────────────┘

PSEUDOCÓDIGO:

   Para cada celda vacía (r, c):
      Para cada thread T:
         Para i = 1 hasta N simulaciones:
            • Copiar tablero
            • Hacer movimiento (r,c)
            • Simular juego aleatorio
            • Contar victoria/derrota
      
      Combinar resultados de threads
      score[r][c] = sum(victorias) - sum(derrotas)
   
   Retornar celda con mayor score

CARACTERÍSTICAS:
   • Paralelismo de datos
   • Sin race conditions
   • Escalabilidad lineal
   • Memory-efficient
