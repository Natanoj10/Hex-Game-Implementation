📄 hex_game.h (1.8K)
   ├─ Propósito: Definiciones, estructuras y prototipos
   ├─ Contiene:
   │  • Definiciones de constantes del juego
   │  • Estructuras: board_t, coord_t, stats_t, thread_args_t
   │  • Prototipos de todas las funciones
   └─ Incluido por: Todos los .c del proyecto

📄 hex_game.c (4.8K)
   ├─ Propósito: Motor principal del juego
   ├─ Funciones principales:
   │  • board_init() - Inicializar tablero
   │  • board_make_move() - Ejecutar movimiento
   │  • board_check_winner() - Detectar ganador con DFS
   │  • board_is_valid_move() - Validar movimientos
   │  • board_get_empty_cells() - Obtener celdas disponibles
   └─ Algoritmos: DFS para conectividad hexagonal

📄 hex_ai.c (7.3K)
   ├─ Propósito: Inteligencia artificial con Monte Carlo
   ├─ Funciones principales:
   │  • ai_best_move() - Función principal de decisión
   │  • monte_carlo_worker() - Worker thread paralelo
   │  • run_simulations() - Ejecutar N simulaciones
   │  • simulate_random_game() - Simular una partida
   └─ Características: Paralelización con pthreads

📄 hex_gui.c (9.5K)
   ├─ Propósito: Interfaz gráfica con raylib
   ├─ Funciones principales:
   │  • main() - Loop principal del juego
   │  • draw_board() - Renderizar tablero
   │  • draw_hexagon() - Dibujar hexágonos
   │  • pixel_to_hex() - Conversión coordenadas
   │  • hex_to_pixel() - Conversión coordenadas
   │  • draw_ui() - Panel de información
   └─ Interacción: Mouse, teclado, eventos

📄 hex_console.c (4.7K)
   ├─ Propósito: Interfaz de consola (alternativa sin GUI)
   ├─ Funciones principales:
   │  • main() - Loop del juego en consola
   │  • parse_move() - Interpretar jugadas (A1, B2, etc.)
   └─ Ventajas: No requiere raylib, útil para debugging

📄 pcg_basic.h (404B)
   ├─ Propósito: Header del generador PCG32
   ├─ Contiene:
   │  • Estructura pcg32_random_t
   │  • Prototipos de funciones PCG
   └─ Nota: Generador de números aleatorios thread-safe

📄 pcg_basic.c (840B)
   ├─ Propósito: Implementación del generador PCG32
   ├─ Funciones:
   │  • pcg32_srandom_r() - Inicializar con seed
   │  • pcg32_random_r() - Generar número aleatorio
   │  • pcg32_boundedrand_r() - Número en rango
   └─ Calidad: Excelente, period 2^64
